# Autonomous Agents

This directory will contain the AI logic (e.g., Python using LangGraph, AutoGen, or raw SDKs).

## Responsibilities
- Implement the Worker and Supervisor agent architecture.
- Execute the ReAct loop (Observe, Reason, Act, Evaluate).
- Ensure strict alignment with the project's "Soul" (Goal).
- Emit structured JSON events to the Orchestrator Server during execution.
