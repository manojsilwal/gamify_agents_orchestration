# Visualization WebUI / Game Engine

This directory will contain the React, Three.js, or Phaser.js application.

## Responsibilities
- Connect to the Orchestrator via WebSockets.
- Listen for agent events.
- Render dynamic UI components (Generative UI) or 2D/3D game sprites based on the agent's actions.
- Provide human-in-the-loop controls (approve actions, halt execution).
